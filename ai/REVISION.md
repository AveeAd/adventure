From milestone 1 and 2 i want to achieve the followings. Check if we are on the right track or we need to revise the system.

## Activity (Adventure)
- The system is more like a community driven application where users can login to the system and add the activity information (any kind of adventure activities)
- Users can update the activity created by anyone to correct mistakes or add updates.
- Users can add photos for that activity
- Users can add trails/spots or update trails by uploading gpx/kml files
- The activity created by users will be unverified when created. Admin and moderators can make it verified manually from the admin site. For automatic we will discuss it when we will create user profile.
- Instead of Like in activity i want to add "Been Here" button, which will marks the users visited count in activity and for users it will show users have visited this place, this will also help to calculate the popular destination and i also want to record when the user visited so that we can calculate the trending activity too - recently most visted activity

## Stories
- Stories are similar to activity but it's a comment like feature for any activity where users will share their story/journal after being there or done that activity.
- For any activity users can create story. In story content should be markdown and users should be able to attach their recorded trails/spots.
- Other users can give kudos and reply with comments to the story.

## Contribution
- Contribution is done in two ways for now: creating activity and updating activity
- When updating activity if the user update content or trails/spot it will be replace by newer and older will be shown in history.
- Contributing with adding image or story is just appending to the existing.
